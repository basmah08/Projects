# MSc Projects Portfolio

A collection of coursework projects from my MSc in Actuarial Science / Actuarial Management, covering statistical modelling, machine learning, and portfolio theory applied to healthcare, insurance, finance, and consumer data.

## Projects

1. [Heart-Disease-Classification](./Heart-Disease-Classification) — Classified coronary heart disease risk using ridge logistic regression and 5 other ML classifiers, benchmarked by accuracy and AUC

2. [Healthcare-Expenditure-MEPS](./Healthcare-Expenditure-MEPS) — Modelled US healthcare spending and doctor-visit frequency using a two-part model and Negative Binomial regression on MEPS survey data

3. [Car-Fuel-Efficiency-Price](./Car-Fuel-Efficiency-Price) — Built linear regression models to identify what car features drive fuel efficiency (mpg-per-dollar) and price using 1985 automotive data

4. [Shrinkage-Estimation-Portfolio-Insurance](./Shrinkage-Estimation-Portfolio-Insurance) — Applied distribution-free shrinkage estimators to portfolio construction (100 S&P 500 stocks) and shrinkage GLMs to insurance claim severity modelling (French MTPL data), evaluated via extensive rolling-window and cross-validated out-of-sample testing

5. [Tree-Based-Methods-Heart-Disease](./Tree-Based-Methods-Heart-Disease) — Compared Decision Tree, Random Forest, and XGBoost classifiers on the Cleveland Heart Disease dataset, with SHAP-based interpretability and an interactive R Shiny client-facing demo

6. [Customer-Segmentation-PCA-Clustering](./Customer-Segmentation-PCA-Clustering) — Used PCA and clustering (K-Means, GMM, Ward's hierarchical) to uncover hidden customer segments in wholesale purchasing data, plus a structured comparison of Claude and ChatGPT performing the same analysis blind

7. [Flood-Risk-Pricing-Underwriting](./Flood-Risk-Pricing-Underwriting) — Tested whether property-level features beat flood-zone-band rating for US flood claim severity, using GLM/GBM/Random Forest models with rigorous out-of-time validation and SHAP-based interpretation, framed as a reinsurance pricing review

---

Each project folder contains its own README with a fuller description, methodology, key results, and tools used. Several were completed as part of group coursework — co-authors are credited within each project's own README where applicable.
